# Kyber
An argb controller for Personal computers
I made this as my JRGB pins on my motherboard doesnt work properly. It could also be modified to support a greater number of ARGB headers.

### Features:
- It has 4 ARGB headers
- It has 1 4 pin molex power connector for a Peripheral connector which connects to the PSU
